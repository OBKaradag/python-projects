# 🚀 Python Projeler ve Algoritma Uygulamaları

Bu depo, temel programlama mantığını pekiştirmek, kullanıcı etkileşimli akışlar kurmak ve ilerideki kapsamlı mühendislik/yazılım sistemlerine sağlam bir temel oluşturmak amacıyla geliştirdiğim ufak çaplı Python uygulamalarını içermektedir.

## 📂 Proje Listesi

Depo içerisinde yer alan her bir Python dosyası, spesifik bir problemi çözmeye veya belirli bir mantıksal yapıyı (koşullar, matematiksel operatörler, kullanıcı girdisi) test etmeye odaklanmıştır:

* **`kullanici_adi_sifre.py`**: Temel string doğrulama, koşul yapıları (if-else) ve basit giriş (login) algoritması simülasyonu.
* **`not_ortalamasi_uygulamasi.py`**: Kullanıcıdan alınan sayısal verilerle matematiksel hesaplamalar yapma ve sonuca göre geçme durumu/harf notu belirleme.
* **`restoran_selamlama.py`**: Kullanıcı girdilerine göre dinamik metin (string) üretimi ve akış kontrolü uygulaması.
* **`tek_mi_cift_mi.py`**: Modulo (`%`) operatörü kullanılarak sayıların matematiksel analizini yapan ve sonucuna göre karar veren temel kontrol mekanizması.

## 🛠️ Kullanılan Teknolojiler

* **Python 3.x**: Projeler standart kütüphane fonksiyonlarıyla (built-in) geliştirilmiş olup harici bir paket kurulumu gerektirmez.

## 💻 Nasıl Çalıştırılır?

Bu depodaki uygulamaları test etmek için:
1. Depoyu bilgisayarınıza indirin (Clone).
2. Sisteminizde Python yüklü olduğundan emin olun.
3. Herhangi bir IDE (PyCharm, VS Code) kullanarak veya komut satırından (Örn: `python tek_mi_cift_mi.py` yazarak) kodları çalıştırın ve ekrandaki yönergeleri izleyerek veri girişi yapın.
